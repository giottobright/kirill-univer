# Практикум МИТиУ — Вариант 7 — план и память проекта

## Задача
Полностью выполнить практикум по дисциплине «Маркетинг ИТ и услуг» (файл
`2026_Практикум_МИТиУ.docx`, 888 параграфов, 50 таблиц) + создать связанный Excel-файл.

## Исходные данные (Вариант № 7)
- Класс ИС: **ИС управления поставщиками (SRM)**
- Дорабатываемый функционал: составление графиков аттестации поставщиков +
  оценка надёжности контрагентов по их аттестации + выявление оптимальных партнёров.
- Компания: **ООО «НОРБИТ»** (ГК ЛАНИТ), продукт «НОРБИТ: Управление закупками (SRM)».
- Новый продукт: «НОРБИТ: Управление закупками (SRM) 2.0» + модуль «SRM.Аттестация».
- Конкуренты (реальные): Comindware («Comindware Управление закупками»),
  Bidzaar («Bidzaar»), АГОРА («AGORA SRM»), 1С («1С:ERP Управление предприятием 2»).
- ФИО / Группа: заглушки `[ФИО студента]`, `[Группа]`, `[Член команды 2]`, `[Член команды 3]`.

## Решения пользователя
1. ФИО/группа — заглушки.
2. Скриншоты внешних сервисов — генерируем диаграммы/визуалы кодом сами.
